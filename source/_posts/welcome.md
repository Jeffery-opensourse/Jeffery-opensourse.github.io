旧站挂在 GitHub 上，账号换了之后一直没搬。这次干脆用 Hexo 重新搭了一遍，写文章还是原来的流程：

```bash
hexo new "标题"     # 写一篇
hexo server         # 本地预览
git push            # 推上去，GitHub Actions 自动构建部署
```

主题换成了 Fluid，比之前的更清爽，支持暗色模式。学术相关的内容单独整理成了两个页面：

- [关于我](/about/) —— 研究方向、教育经历、联系方式
- [论文与成果](/publications/) —— 论文、专利、项目

以前的几篇旧文都保留了，原来的链接还能打开。
